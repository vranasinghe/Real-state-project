# Aura Space

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product Purpose
An existing property discovery, favorites, enquiries and seller/agent dashboard application, paired with a historical Ames house-price machine-learning demonstration and a recruiter-facing project case study.

## Capabilities and Constraints
Preserve React 18, Vite, Tailwind, React Router, Supabase and FastAPI. Preserve all routes and the saved 50/50 Ridge and Gradient Boosting ensemble. The estimator accepts 18 inputs, predicts USD sale prices using Ames, Iowa sales from 2006–2010, and is unsuitable for contemporary valuations, other markets or rentals. Estimate ± test MAE is an error reference, never a calibrated confidence interval. Uncollected model features use stored defaults.

## Brand Commitments
Aura Space; emerald #27AE60, forest #1A3C34, warm white, Plus Jakarta Sans headings and Inter body. Restrained, accessible, responsive interfaces with real estate imagery.

## Evidence on Hand
backend/artifacts/model.joblib, backend/train_model.py, backend/report/report.json and six report figures. Reported held-out test R² 0.9049 is on log-price scale; MAE $13,981, RMSE $21,673. Local listings and agents are demonstration data. No verified customer testimonials supplied.

## Product Principles
Real inference; honest scope and evaluation; preserve existing integrations; no fabricated market or customer claims; visible failure and recovery states.
